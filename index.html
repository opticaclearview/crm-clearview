Conecta la base de datos para sincronizar entre dispositivos

¿Por qué necesito esto?
Supabase es una base de datos gratuita en la nube. Te permite acceder al CRM desde cualquier dispositivo (PC, celular) sin perder datos aunque borres el caché.
1
Ve a supabase.com → crea una cuenta gratuita → crea un nuevo proyecto.
2
En tu proyecto ve a SQL Editor y ejecuta el script de creación de tablas (ver botón abajo).
3
Ve a Settings → API → copia la Project URL y la anon public key.
4
Pega ambas claves aquí abajo y haz clic en Conectar.
